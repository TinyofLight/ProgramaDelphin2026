# ProgramaDelphin2026
Este proyecto surge como evolución de un trabajo realizado durante las Estancias del Programa Delfín en el Tecnológico de Estudios Superiores de Coacalco (TESCo), bajo la tutoría del Mtro. Roberto Carlos Muñoz Celaya, basado en un sistema de traducción de Lengua de Señas Mexicana para personas con discapacidad del habla.
